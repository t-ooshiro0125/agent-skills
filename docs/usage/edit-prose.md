# edit-prose

既存の日本語文章を、意味と温度感を保って確認・リライトします。短い報告文も対象です。文章の目的と依頼条件を踏まえて構成・形式を判断してから表現を整え、短縮した場合も情報の関係や確認しやすさを保てているか確かめます。ルール・運用文書には [edit-rulebook](edit-rulebook.md) を使います。

検索・参照する技術記事などでは、見出し・表・箇条書きから要点や条件を探せるかも確認します。共通の軸での比較には表、見落としを防ぐ必要がある箇所には最小限の強調を検討し、冒頭の要約は情報へたどり着きやすくなる場合に使います。利用先の書式に合わせ、短いメールやエッセイなどに不要な表・要約・強調を加えず、理由や因果関係、条件・例外を保ちます。

読者の前提知識と説明不足も確認します。原文にある情報で関係を明確にし、新しい情報が必要な箇所は不足として示します。原文外の情報を調べた追加案が必要な場合は [review-docs](review-docs.md) を使い、採用した案の反映は編集依頼の範囲で行います。言い換えや要約でも、根拠・断定の強さ・確認範囲を保ちます。

関連文書がある場合や、文書構成の見直しが依頼に含まれる場合は、文書間の配置も確認します。単独の短いメールや報告文などに、一律に別文書への分割判断は求めません。

## 依頼例

確認のみでは文章を編集せずに問題のある箇所・理由・必要な修正案を示し、リライトでは修正文を提示します。

```text
$edit-prose この文章を、意味と温度感を保って読みやすくしてください。対象: …
```

エージェント向けの手順は [SKILL.md](../../skills/edit-prose/SKILL.md) を参照してください。
