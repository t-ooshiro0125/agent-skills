# edit-rulebook

指示・ルール・運用文書を、元の条件と要求を保って確認・リライトします。表現を整える前に、文書の目的・読者・役割に応じて、文書内の整理と別文書への移動・分割を判断します。

読者の前提知識と、用語・前提の説明も確認します。原文外の情報が必要な箇所は不足として示し、追加案の調査・提案は [review-docs](review-docs.md) で行います。採用した案の反映は編集依頼の範囲で行い、根拠・断定の強さ・確認範囲も保ちます。

移動先が既存構成から明らかで編集依頼に含まれる場合は整理を進めます。ユーザー判断が必要な場合は、それに依存するリライトや細かな表現案だけを保留し、他の確認・編集を続けます。

## 依頼例

確認のみでは文章を編集せず、問題のある箇所と理由を示し、必要に応じて修正案を添えます。リライトでは修正文を提示します。

```text
$edit-rulebook AGENTS.md の条件や対象範囲に曖昧さがないか確認し、元の要求を保って整理してください。
```

[edit-prose](edit-prose.md) の編集原則を参照します。このリポジトリの個別リンク方式では、参照だけなら追加登録は不要です。`edit-prose` を名前で直接呼び出したい場合は追加登録してください。詳しくは [依存スキルの扱い](install-skills.md#依存スキル) を参照してください。

エージェント向けの手順は [SKILL.md](../../skills/edit-rulebook/SKILL.md) を参照してください。
