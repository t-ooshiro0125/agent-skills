# implementation-challenge

実装レビューの結果と議論の結論に対して反証を試みます。文書レビューの指摘や改訂案の再検証には [challenge-docs](challenge-docs.md) を使います。

## 依頼例

```text
$implementation-challenge このレビュー結果と議論の結論を検証してください。
```

エージェント向けの手順は [SKILL.md](../../skills/implementation-challenge/SKILL.md)、表示用メタデータは [agents/openai.yaml](../../skills/implementation-challenge/agents/openai.yaml) を参照してください。
