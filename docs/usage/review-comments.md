# review-comments

コード内コメントの必要性・簡潔さ・重複・読みやすさと、実装との整合性を確認します。ファイルは編集せず、問題の箇所・理由・削除や書き換えなどの具体案を提示します。

## 依頼例

```text
$review-comments 現在の差分について、コメントが簡潔で読みやすいか、冗長・重複・不要な説明がないか確認してください。
```

```text
$review-comments src/cache.py のコメントをレビューしてください。必要な理由や制約を残しながら、短縮・統合できる箇所を挙げてください。
```

対象の指定がなければ、現在の差分で追加・変更されたコメントと、コード変更の影響を受ける既存コメントを確認します。短さだけを理由に、必要な設計判断の理由・制約・注意点を削る提案はしません。PR のレビューコメント本文や、独立した文書は対象外です。

一連のレビューには [review-workflow](review-workflow.md) を使います。コメントだけを確認する場合は、このスキルを直接呼び出してください。

エージェント向けの手順は [SKILL.md](../../skills/review-comments/SKILL.md)、表示用メタデータは [agents/openai.yaml](../../skills/review-comments/agents/openai.yaml) を参照してください。
