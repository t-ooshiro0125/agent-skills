# review-handoff

レビュー後の判断を、開発者向けの対応指示にまとめます。

## 依頼例

```text
$review-handoff このレビュー結果と確定した判断を、開発者向けの対応指示にまとめてください。
```

レビュー結果と確定した判断を対象にします。一連のレビュー工程には [review-workflow](review-workflow.md) を使用してください。

エージェント向けの手順は [SKILL.md](../../skills/review-handoff/SKILL.md)、表示用メタデータは [agents/openai.yaml](../../skills/review-handoff/agents/openai.yaml) を参照してください。
