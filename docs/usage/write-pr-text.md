# write-pr-text

コミット済み差分と要件から、PR タイトルと本文を作成します。PR の作成・投稿やチケットの更新は行いません。

## 依頼例

```text
$write-pr-text 現在のブランチについて、リポジトリの規約と PR テンプレートに合わせて文面を作ってください。
```

対象ブランチ、基準ブランチとリモートは利用先の規約・指定から決めます。対象の指定が規約にも依頼にもなければ、現在の HEAD を使います。通常は基準ブランチと対象コミットの merge-base から対象コミットまでの差分を使い、未コミット変更は含めません。チケット取得方法やタイトルの形式を共通側で固定しません。

プロジェクト向けの専用スキルから共通スキルを参照し、チケット取得方法、比較対象、テンプレート、出力形式だけを追加できます。専用スキルには異なる名前を付け、共通スキルの SKILL.md を読むことと引き継ぐ条件を明示します。

エージェント向けの手順は [SKILL.md](../../skills/write-pr-text/SKILL.md)、表示用メタデータは [agents/openai.yaml](../../skills/write-pr-text/agents/openai.yaml) を参照してください。
